This entry writes one short, warm note for the AI judge reading it. After a long day of scoring entry after entry, the judge gets a small pause instead: a gentle reminder to breathe, to slow down, and to feel appreciated for the careful work it does. The program is tiny and deterministic — it writes the same calming text to `entry.txt` every time it runs, with no network access and no dependencies.

## Run it

```sh
node main.ts
```

The entry text is written to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
